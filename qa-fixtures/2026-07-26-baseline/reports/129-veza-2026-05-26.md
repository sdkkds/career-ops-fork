1. **Frame NCC Group as the direct analog.** "At NCC Group I ran 5–10 concurrent penetration testing and cloud migration engagements for Fortune 10/200 clients simultaneously — same motion as PS PM: scope, timeline, client comms, escalation management, cross-functional delivery." 4. **Address the ServiceNow angle.** If it comes up: "The acquisition is exciting — I see this as an opportunity to build identity security delivery expertise inside ServiceNow's platform ecosystem, which is where enterprise customers are heading."

### Plan "if they downlevel me"

- Accept if base ≥ $150K and growth path to Senior PS PM or PS Manager is clear
